# 首次启动：本地保存说明

## 页面目标

用一屏非技术语言说明三个事实：哪些数据默认留在本机、什么时候会发送到远程模型、API 密钥如何隔离。用户可以直接继续，不设置复选框、不要求逐条确认。

## 内容层级

1. 顶部：织卷字标 + 次要动作“跳过说明”；
2. 主标题：“你的故事，先留在这台设备上”；
3. 一句摘要；
4. 三个信息块：默认留在本机、远程生成边界、密钥单独保护；
5. 主动作：“继续设置”；
6. 主动作下说明下一步只需选择服务并粘贴密钥。

## 页面规则

- 背景使用暖纸色，内容块只用细边框区分；橙色只标记信息编号和重点句，不做大面积背景。
- 页面整体可滚动，主按钮放在内容流中，确保横屏和 200% 字体可达。
- 顶部跳过和底部继续进入同一连接步骤；不在此时记录“首次引导完成”，有效连接创建后才能完成引导。
- 从连接步骤按系统返回键回到本说明；从本说明按返回键交还系统。
- “跳过说明”和“继续设置”均使用原生按钮、48dp 以上触摸高度和明确 TalkBack 文案。
- 同时提供浅色和深色语义颜色；不加入自动播放或装饰动画。
