# 连接向导页面规范

> 页面任务：让不了解 API、协议、token 或模型能力的用户，用最少操作建立一个可用于后续生成的连接。继承 `../MASTER.md`；本页规则优先。

## 1. 默认路径

1. 默认选择“官方服务 / DeepSeek”，同时提供 OpenAI、Anthropic、Gemini。
2. 用户只需粘贴 API 密钥并点击“检查并获取模型”。
3. 基础检查只读取模型列表，不生成文本；成功后自动选择一个适合文本生成的模型。
4. 用户通常直接点击“使用此连接”，无需理解协议、上下文窗口或能力字段。
5. “完整验证”位于高级动作，点击后再次说明固定测试语句、最多 16 tokens 和可能产生极少费用，确认后才发送。

中转站路径只多一个“基础地址”字段。只有服务端明确拒绝/不提供模型列表端点时，页面才显示手填模型；鉴权、网络、额度、TLS 或未知错误不能借手填入口绕过。

## 2. 信息层级

- 顶部：返回、页面标题、一句无术语说明。
- 第一段：来源切换；官方服务用 2×2 单选卡，中转站显示 HTTPS 地址字段。
- 第二段：密钥字段与唯一主动作。
- 结果段：基础通过、需手填或失败三类文字状态；状态不能只靠颜色。
- 成功后：自动推荐模型卡；“更换”属于次级动作。
- 底部：高级完整验证与“使用此连接”。

## 3. 密钥交互

- 密钥输入不使用 `rememberSaveable`，不随配置重建保存原文。
- 点击检查后立即把界面原文清空，将字符缓冲转入 Android Keystore Secret Store。
- 测试失败时只显示 `••••尾四位`，网络恢复后允许直接重试；用户可明确选择“更换”。
- 换服务、换地址或退出向导时撤销临时 secret；进程异常重启时根据 no-backup 临时引用撤销残留 secret。
- 页面、错误文案、日志和报告不得显示完整 secret、`secretRefId`、服务商原始错误正文或响应正文。

## 4. 视觉状态

| 状态 | 表现 | 主动作 |
|---|---|---|
| 未填写 | 暖纸背景、浅色字段、按钮禁用 | 检查并获取模型 |
| 检查中 | 原按钮内小型进度，禁止重复点击 | 正在检查 |
| 基础通过 | 中性浅层卡 + 明确标题；显示推荐模型 | 使用此连接 |
| 模型列表不可用 | 说明“尚未验证”，出现单一模型字段 | 使用此连接 |
| 失败 | 错误色边框/浅底 + 原因 + 一个修复动作 | 重新检查/更换密钥 |
| 完整验证确认 | Material 对话框，说明最多 16 tokens 和费用 | 确认并验证 |

选中来源使用浅赭容器与文字/边框双重提示，不采用默认紫色；橙色只用于段落序号、当前服务边框和状态强调。

## 5. 响应式与无障碍

- 页面应用 safe drawing inset、全页滚动和 560dp 最大内容宽度。
- 所有可点击目标至少 48dp；主按钮至少 56dp。
- 标题暴露 heading 语义；视觉和 TalkBack 顺序一致。
- 200% 字号与横屏下，服务卡、输入区、结果和底部动作都必须能滚动到达。
- 模型较多时使用可搜索弹窗与有界 LazyColumn，不把上万个模型直接组合进主页面。
- 密钥字段使用 password 键盘和遮蔽显示；禁用态仍需保持可辨识文字对比。
