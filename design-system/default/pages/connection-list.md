# 连接列表页面规范

> 页面任务：让用户几乎不用管理 API，同时始终知道织卷会使用哪个连接。继承 `../MASTER.md`；本页规则优先。

## 1. 默认信息层级

1. 标题“模型连接”和一句低术语说明；
2. 唯一顶部主动作“添加新连接”；
3. 当前连接固定第一，使用浅赭容器、2dp 强调边框和“当前”标签；
4. 其他连接使用纸白卡片，仅显示必要状态；
5. 非当前连接允许一键设为当前，编辑和删除按需进入。

## 2. 连接卡片

- 显示：自定义名称、模型 ID、host、验证状态、`••••尾四位`；
- 隐藏：原始密钥、`secretRefId`、完整 URL 的 query、能力底层字段和服务商响应；
- 验证状态使用文字，不只靠颜色；手填未验证使用错误色提示，但不自动打断用户；
- 名称和模型允许两行以内，长文本省略；卡片本身不承担隐式点击，所有动作有明确文字。

## 3. 编辑与删除

- 编辑弹窗默认只提供连接名称和模型；模型列表可用时必须从已发现模型中选择；
- 地址或密钥变化采用新建连接流程，验证成功后再删除旧连接；
- 删除入口放在编辑弹窗中，必须二次确认；文案说明会撤销密钥但不会删除小说；
- 删除当前连接且仍有其他连接时，事务内自动选择确定性后备连接。

## 4. 响应式与无障碍

- safe drawing inset，内容最大宽度 680dp；列表采用 LazyColumn；
- 按钮至少 48dp，添加主动作至少 56dp；
- 200% 字号与横屏时，通过列表滚动到达所有连接和操作；
- 当前状态使用容器、边框和文字三重表达，浅深主题均不得只靠颜色。
