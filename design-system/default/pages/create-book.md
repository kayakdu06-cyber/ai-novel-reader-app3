# 极简创建页面规范

> 页面任务：用户只写一句故事设想即可继续，题材、篇幅和呈现均有可靠默认值。继承 `../MASTER.md`；本页规则优先。

## 1. 默认路径

1. 已有当前连接时，启动后直接进入“织一本新书”；
2. 用户输入一句故事设想；
3. 题材默认“不限定”，常用题材直接可选，其余题材放入“更多题材”；
4. 篇幅默认“中篇（最低 300 章）”，呈现默认“均衡”；
5. 点击唯一主动作“开始织书”，把结构化输入交给后续标准化与费用确认，不在本页直接调用模型。

默认路径不要求理解模型、token、提示词、内部内容维度或章节规划。人物、关系、世界、视角、节奏和文风已经收进“再补充一点”，只有用户主动展开时出现。

## 2. 信息层级

- 标题和一句说明；
- 当前连接摘要：只显示连接名称和模型，提供“管理”次动作，不显示密钥尾号；
- 唯一必填项“你想读一个什么故事？”；
- 题材、篇幅、呈现三个选择区；
- 主动作与“确认前不会调用模型”的说明。

不显示成人、色情等直白分类名称。`细写`的技术含义由 PR-004 和后续内容映射负责，页面不靠露骨文案表达。

## 3. 选择控件

- 题材由页面外部的可版本化目录提供，UI 不硬编码业务列表；常用项先展示，完整 13 类在弹窗中单选；
- 篇幅使用三张整行单选卡：短篇最低 80 章，中篇最低 300 章，长篇由用户填写目标章数；
- 只有选择长篇时才在篇幅卡片后显示数字输入；字段默认留空并由用户填写 301–10,000。空值使用中性必填说明，越界值就地显示原因并禁用主按钮，不弹额外对话框；
- 呈现使用三张整行单选卡：留白、均衡、细写；说明具体但克制；
- 选中状态同时使用单选控件、边框和文字，不只依靠颜色；
- 所有卡片整行可点，目标高度至少 64dp。

## 4. 输入与状态

- 故事设想使用持久可见标签，不以 placeholder 代替标签；支持多行中文，当前里程碑上限 2,000 字符；
- 空白时主按钮为原生禁用状态，说明“一句话就能开始”；
- 文本、题材、篇幅和呈现使用 `rememberSaveable`，Activity 重建后保留；
- 点击主动作只提交一次结构化 `MinimalBookDraft`，后续异步阶段必须显示反馈并防重复提交；
- 本页不保存 API 密钥、不展示 secret 尾号、不发起网络请求。

## 5. 响应式与无障碍

- 单一 LazyColumn，safe drawing inset，内容最大宽度 600dp；不使用嵌套滚动；
- Android 触摸目标至少 48×48dp，主按钮至少 56dp；
- 200% 字体、375dp 等效窄屏与横屏下可滚动到达主动作；
- 标题为 heading；字段、单选组和按钮有清晰语义与按压反馈；
- 浅色和深色均使用现有语义色，不采用检索结果中的 AI 紫色、粉色或联网字体。

## 6. 任务交接

- TASK-034 增加“再补充一点”高级折叠区；
- TASK-035 固化呈现档位到内部 content-control schema 的映射；
- TASK-036 已创建不可变快照与书记录；TASK-037 接入真实用量估算和最终确认。

## 7. TASK-034 高级折叠区

- “再补充一点（可选）”位于呈现档位与主按钮之间，默认折叠；整行使用原生按钮语义、至少 56dp 高，并同时用“展开/收起”文字说明状态；
- 展开后按五组常驻标签接收自然语言：人物与关系、世界与背景、叙事与文风、希望保留、不想出现；所有字段可空，不使用专业术语逐项审问；
- 人物帮助文字仅在高级区展开后出现：“若包含亲密关系，请写明相关人物均为 18 岁以上”；默认页面仍不显示直白内容尺度名称；
- 已填写项数量显示在折叠入口中，折叠只隐藏字段、不清空值；
- 五组输入分别限制字符数，并在字段下方显示计数，避免无界表单进入后续提示；
- 高级值以独立结构随 `MinimalBookDraft` 原样提交；TASK-036 的统一标准化器负责 NFC、换行/空白整理、来源标记和不可变快照，避免 UI 与存储各自修剪导致原始输入丢失；
- 所有字段和展开状态使用 saveable state；页面路由使用 SaveableStateHolder，确保旋转、Activity 重建和进入连接管理后返回均不丢失；
- 继续使用单一 LazyColumn，不在高级区嵌套滚动或使用装饰性展开动画；200% 字号、横屏和 375dp 等效宽度下必须可滚动到主按钮。
