# 织卷设计系统总则

> 本文件以用户确认的“多看阅读沉浸体验 + 起点信息组织”为主基线；UI/UX skill 的可访问性、触摸、布局和主题规则作为工程约束。页面专属规则位于 `pages/`，并优先于本文件。

## 1. 产品气质

- 中文内容优先、克制、安静，不把 AI 能力做成控制台。
- 暖纸色是主要阅读与引导基调，深墨色承载正文，橙色只用于主动作和当前状态。
- 不使用促销、会员、社区、积分或聊天机器人式装饰。
- 功能按需出现；默认路径只保留完成当前任务所需的操作。

## 2. 语义颜色

| 角色 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| Background | `#F6F0E5` | `#171411` | 页面底色 |
| Surface | `#FFF9EF` | `#24201C` | 卡片/内容层 |
| Primary | `#211D19` | `#F5EEE4` | 主文字、深色按钮 |
| OnPrimary | `#FFFFFF` | `#1A1714` | 主按钮文字 |
| SecondaryText | `#615A52` | `#CFC5B9` | 说明文字 |
| Accent | `#B45525` | `#E28A55` | 单点强调、当前状态；正文大小文字对比均 ≥4.5:1 |
| Outline | `#D8CDBF` | `#51483F` | 分隔与边框 |
| Error | `#B3261E` | `#FFB4AB` | 错误 |

颜色不能独自表达状态，必须同时有文字或语义。

## 3. 排版与间距

- 使用 Android 系统中文字体，避免联网字体和首屏字体闪烁。
- 正文基准不小于 16sp；引导说明使用 17–18sp 与 1.5 倍以上行高。
- 标题可以使用较高字重，但不使用全大写英文或装饰性小字堆叠。
- 间距只使用 4/8dp 节奏；页面常用 16、24、32、48dp。
- 手机内容宽度自适应；平板长文本最大 560dp，避免横向过长。

## 4. 交互与无障碍

- Android 触摸目标至少 48×48dp，相邻目标至少 8dp。
- 使用 Material 原生按钮和按压反馈，不用无语义容器冒充按钮。
- Edge-to-edge 页面必须应用 safe drawing insets。
- 所有说明页可纵向滚动；系统字体 200% 和横屏时主动作仍可到达。
- 返回键遵循页面历史：子步骤返回上一步，首屏返回系统。
- 不使用装饰性循环动画；状态切换使用系统默认反馈并兼容减少动态。
- TalkBack 顺序与视觉顺序一致，标题标记为 heading，图片按是否传达信息决定标签。

## 5. 视觉元素

- 临时 Logo 只能按原比例使用，不重绘、不拉伸、不擅自改色；不适合页面时可只显示“织卷”字标。
- 不用 Emoji 充当功能图标。
- 同层级图标保持相同线型与 24dp 视觉尺寸、48dp 点击范围。
- 卡片以边框和背景层级区分，避免大面积阴影和浮夸玻璃效果。

## 6. 发布前检查

- 浅色/深色文字对比与边框可辨识；
- 375px 等效窄屏、横屏、平板、最大系统字体均可完成任务；
- 所有触摸目标 ≥48dp，焦点/按压/禁用状态清晰；
- 无内容被状态栏、导航栏或固定 CTA 遮挡；
- 无不必要动画、横向手势冲突或仅靠颜色表达的状态。
