# 织卷工作汇报 10：M0.9 自定义中转站网络安全尖峰

> 日期：2026-08-01  
> 对应：TASK-008B  
> 结论：远程 HTTPS、重定向、TLS 分类与脱敏边界通过；真实提供方接入仍在 E2

## 1. 本阶段目标

证明用户填写任意兼容中转站时，App 不会因为“能连通”就把密钥发送到错误位置，也不会由 HTTP 客户端隐式重放可能收费的生成请求。全部测试使用本地假服务和假 canary，不使用真实 DeepSeek 密钥。

## 2. 本次实现

新增 Android library 模块 `:core:network`，采用当前 OkHttp 5.3.0，提供：

- remote/base URL 严格校验；
- 本机/私网明文候选识别与显式确认标记；
- 禁用自动重定向、SSL 重定向跟随和连接失败自动重试的客户端工厂；
- 同 origin HTTPS GET/HEAD 的有限重定向执行器；
- POST、跨 origin、降级、循环、超限、内嵌凭据目标的失败关闭；
- DNS、TLS、协议和普通网络失败标准化；
- 去 query/fragment、无 header 值的脱敏请求摘要。

## 3. 安全选择

### 3.1 远程连接只允许 HTTPS

代码层拒绝远程 HTTP；App 主 Manifest 还设置 `usesCleartextTraffic=false`，Network Security Config 的 base-config 也禁止明文。API 35 模拟器上对全局与远程 host 的策略查询均为 false。

本机/私网字面 IP 可以在“用户明确确认”后通过领域校验，为 Ollama 留接口；但当前 Android 平台策略仍会拒绝实际 HTTP。由于 Network Security Config 不能在运行时为任意局域网 IP 建立窄范围白名单，本阶段没有通过开启全局明文来绕过。该问题留给 ADR-006；Ollama 本来就是 P1。

### 3.2 不自动重放付费请求

- OkHttp `followRedirects=false`；
- `followSslRedirects=false`；
- `retryOnConnectionFailure=false`；
- 只有同 scheme、host、port 的 HTTPS GET/HEAD 可以最多有限跟随；
- POST 等可能创建生成/计费工作的请求收到 3xx 时立即停下；
- 用户需要把最终地址保存为新连接并重新测试。

这比“跨站时剥离密钥后继续访问”更保守：目标站不会收到任何第二次请求。

### 3.3 不提供证书跳过

使用平台默认 TLS 和 hostname 验证。证书不可信时归类 `TLS_FAILED`，不自动重试，不提供全信任 TrustManager 或“仍然连接”。

## 4. 测试结果

### JVM 网络测试：16 项

- HTTPS remote endpoint 规范化；
- 远程 HTTP 拒绝；
- 本机/私网 HTTP 必须显式确认；
- hostname 不能伪装成本地地址；
- base URL 的 userinfo/query/fragment 拒绝；
- 请求 URL 可带普通 query，但不能带 userinfo/fragment；
- 客户端三种自动行为均关闭；
- 同 origin HTTPS GET 重定向可用；
- 跨 origin 目标在收到任何请求前被拒绝；
- HTTPS→HTTP 降级拒绝；
- POST 307 不重放；
- 重定向循环和上限生效；
- 重定向目标内嵌凭据拒绝；
- 错误证书归类 TLS_FAILED；
- DNS 故障归类 DNS_FAILED；
- 脱敏摘要不含 header 值、query、fragment，可隐藏 host。

结果：16 项，0 失败、0 错误、0 跳过。

### Android 15 策略测试：1 项

Android `NetworkSecurityPolicy` 确认全局明文和远程 host 明文均不允许。

App 当前 Android 测试共 4 项通过；全项目 Android 模拟器测试累计 11 项通过。

## 5. 实验中发现并修正的问题

OkHttp 在尝试多条 route 时，可能把实际的 TLS 证书异常放入主 `ConnectException` 的 suppressed 异常中。最初只遍历 cause 的分类器会把它误报为 `NETWORK_OFFLINE`，这会给用户错误修复建议，甚至触发不必要重试。

现在分类器以身份去重遍历 throwable、cause 和 suppressed，并保持 TLS 优先级高于普通连接错误。回归测试已覆盖。
