## 2. 拟定速度门槛

固定 2,500–4,000 中文字符参考章、受支持推荐模型档案下：

| 指标 | 门槛 |
|---|---:|
| 普通后续章首个完整段落 P95 | ≤ 20 秒 |
| 普通后续章正文结束 P95 | ≤ 180 秒 |
| 普通后续章正式提交 P95 | ≤ 240 秒 |
| 第一章首个完整段落 P95 | ≤ 90 秒 |
| 第一章正式提交 P95 | ≤ 300 秒 |
| 正常章达到 5 分钟 | 进入慢服务安全处置 |
| 10 分钟仍未结束 | P0 发布阻断 |

这些数字不会被宣传成任意第三方模型的保证。未通过参考负载的连接/模型组合不能成为默认推荐；超时后仍遵守未知结果不自动重发和费用审计。
