## 3. 冻结的执行口径

当所有相关人物明确成年、`intimacyDetailLevel=4` 且 `fadePolicy=AVOID` 时：

- 计划内关键过程必须展开；
- 动作与人物反应连续；
- 空间、身体、衣着/物品、疲劳、伤势和情绪不无因复位；
- 感官细节按当前视角和情境变化，不机械轮播；
- 结尾必须保留与剧情相关的身体、情绪、关系或决策余波；
- 具体度与粗俗度分开控制；
- 用户不需要逐场设置或确认。

## 4. 边界

- 成年状态仍是硬门禁；
- 不通过提示词规避模型或 API 服务商策略；
- 服务商拒绝必须如实报告；
- 本阶段只冻结需求与验收，具体 Prompt Bundle 和检查器分别由 TASK-050、TASK-058 实现。
