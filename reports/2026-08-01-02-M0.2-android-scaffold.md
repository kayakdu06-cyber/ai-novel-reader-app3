## 构建中发现并修正

1. AGP 9 默认使用 built-in Kotlin，继续应用 `org.jetbrains.kotlin.android` 会直接失败；现已移除旧插件。
2. 本机只有 JDK 21；JVM 模块改为使用当前 JDK 编译、明确输出 Java 17，避免 Gradle寻找不存在的 JDK 17 安装。
3. Gradle 9.4.1 的 JUnit 运行需要显式 platform launcher；已加入测试运行依赖。
4. Lifecycle 2.11.0 要求 compileSdk 37；本阶段固定到兼容 API 36 的稳定版 2.10.0。
5. Gradle 官方 services 地址对 Java 产生 GitHub DNS 跳转问题；Wrapper 改用官方 `downloads.gradle.org`，并保留 SHA-256 校验。
