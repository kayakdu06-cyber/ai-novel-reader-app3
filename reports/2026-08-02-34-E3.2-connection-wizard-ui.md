## 少操作与密钥安全

- 默认路径是“保持默认服务 → 粘贴密钥 → 检查 → 使用”，不要求理解协议或 token。
- 密钥输入不进入 `rememberSaveable`；开始检查后立即清掉界面原文与字符缓冲。
- 失败时只显示安全存储中的尾四位，网络恢复后可直接重试，不必再次粘贴。
- 换服务、换地址或退出向导会撤销临时 secret；若进程在中途结束，下次构造向导时根据 no-backup 临时引用撤销遗留 secret。
- 远程 HTTP 中转在创建 secret 前拒绝；网络与 Secret Store 工作切到 IO 调度，不阻塞 Compose 主线程。
