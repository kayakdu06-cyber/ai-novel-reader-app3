# 织卷工作报告 49：E4.7 暂停、继续、停止与取消

> 日期：2026-08-02  
> 对应任务：TASK-046  
> 结论：完成并通过双模拟器、全项目离线构建与安全门禁

## 1. 本阶段交付结果

织卷现在具备可恢复、可审计的生成控制底座。暂停、取消当前章和停止不再只是界面布尔值，而是先写入父 `GenerationJob`，再与当前执行器完成安全点握手。

- 发送前暂停：当前 Stage 原子回到 `READY`，Job 进入 `PAUSED`，旧租约立即失效，不创建 Attempt，也不打开 Provider；
- 在途暂停/取消：执行器取消 Provider、强制刷新 Keystore 加密草稿，然后原子取消 Attempt、把 Usage 结算为 FINAL、回队 Stage 并暂停 Job；
- 停止全书：停止可覆盖进行中的暂停；安全点后取消全部非终态 Stage，保留已经成功的章节、草稿和用量台账；
- 继续：只把带用户暂停/取消来源的 Job 恢复到 `READY`，不会因为点击一次继续就直接发出远程请求；
- 本地校验/提交：暂停不会撕裂事务。校验失败先保留 `FORMAT_INVALID` 和修复资格再暂停；当前章提交成功后暂停下一 Stage；末 Stage 完成时允许 Job 正常完成；
- 崩溃恢复：控制意图已经持久化时不会丢失；活动执行器消失后，可在精确租约到期边界代为完成暂停/停止安全点；
- 迟到回调：发送、流开始和结果写入都受父 Job、当前 Stage、Attempt、租约与单调时间共同栅栏，不能把暂停/停止后的任务复活。

## 2. 主要实现

### 2.1 状态机与持久事务

- Job 合法转换扩展为 21 个，覆盖启动前停止、READY 直接暂停/停止、停止覆盖暂停、暂停时末 Stage 完成，以及 PAUSED/NEEDS_ACTION/BLOCKED 的停止；
- Stage 合法转换扩展为 35 个，新增网络安全点回队，并允许父停止取消每一种非终态 Stage；
- 新增 `GenerationControlRepository`，统一提供 `requestPause`、`cancelCurrentChapter`、`requestStop`、`resume`、活动 Attempt 安全点结算和租约到期代结算；
- 控制来源使用固定枚举，不把自由文本、正文或敏感数据写入控制原因。

### 2.2 联网门禁与执行器握手

- `claimForProviderOpen` 在同一 Room 事务中核对发送许可、父 Job 必须为当前 `RUNNING`、当前 Stage 和有效租约；
- `recordRequestIntent`、`recordRequestSent`、`recordStreamStarted` 和正常响应完成均增加父 Job/currentStage 门禁；
- `AuditedStreamingProviderExecutor` 增加独立控制轮询；命中持久控制后调用适配器取消、flush 加密草稿并完成数据库安全点；
- Provider 不支持远程取消或取消调用异常时，仍完成本地安全点；由于服务端费用可能已经发生，用量不会被写成 0。

### 2.3 并发顺序修复

设备测试发现心跳与“请求已发送”可能并行提交：较晚取得的时间戳若先落库，会让合法回调被误判为时间倒退。

现已把同一次执行中的 Stage 心跳、请求已发送和流已开始写入放入同一持久化互斥序列。控制轮询和 Provider 收流仍并行，因此不会用串行网络换取一致性。

### 2.4 正式章节与校验安全点

- `ChapterGenerationCommitRepository` 接受 `PAUSING` 的当前 Job 完成本地提交；
- 有下一 Stage 时，当前章、派生记忆、Usage 和当前 Stage 正常提交，下一 Stage 置为 `READY`，Job 原子进入 `PAUSED`；
- 没有下一 Stage 时，暂停请求不阻止已经完成的末章把 Job 正常推进为 `COMPLETED`；
- 结构化校验失败与 Job 从 `PAUSING → PAUSED` 在同一事务完成，避免留下永久“暂停中”。

## 3. 关闭的严重风险

| 风险 | 结果 |
|---|---|
| 点暂停后仍可能打开 Provider | 父 Job 门禁 + claim 事务复核 + 调用前/收流中控制复查 |
| UI 显示停止但 Attempt 仍活动 | Attempt、FINAL Usage、Stage、Job 同事务结算 |
| 停止后未来章节在重启时复活 | 所有非终态 Stage 原子取消 |
| 暂停丢失已付费增量 | Provider cancel 后强制保存加密草稿，再提交安全点 |
| 迟到回调复活 Stage | 父 Job、当前 Stage、Attempt、租约、时间五重门禁 |
| 心跳与发送回调时间顺序反转 | 单次执行的持久写入互斥序列 |
| 暂停发生在校验失败时永久卡住 | 错误证据与 PAUSED 同事务 |
| 暂停撕裂正式章节提交 | 当前章完成后暂停下一章；停止与提交按事务顺序裁决 |
| 执行器崩溃后 PAUSING 永久悬挂 | 精确租约到期代安全点 |
