# 织卷验收标准

## 1. MVP 验收

MVP 只有全部满足以下条件才可称为“可日常试用”，否则只能称内部原型。

### 创建与连接

- [x] 首次启动用非技术语言说明本地保存、远程发送和密钥隔离；可跳过说明，返回流程可预测，200% 字体仍可完成。
- [x] 只输入一句中文设想可创建本地书记录和不可变快照，并进入从该快照回读的开始前确认页；首生成阶段按后续任务继续。
- [x] 创建草稿将短篇固定为最低/初始目标 80 章、中篇固定为最低/初始目标 300 章；长篇字段默认留空，只有用户填写 301–10,000 的有效目标才可继续。
- [x] 五组高级补充默认折叠且均可留空；折叠、Activity 重建和连接管理往返不丢输入。
- [x] 开始前确认只显示冻结的书名、章数和模型；价格目录未知时不显示 0 或猜测金额，快照不可读时停止并允许返回，当前占位确认不调用模型。
- [ ] 官方连接和 OpenAI 兼容连接能自动测试并给出准确错误。
- [ ] 默认连接测试不发送生成请求；可选完整验证有费用确认、单请求、16-token 硬上限和 60 秒全程上限。
- [ ] 模型列表不可用时可手填并标记未验证，但错误密钥、额度或网络错误不能借此绕过。
- [ ] 密钥只显示尾部，不出现在数据库可见字段、日志、模板和备份。
- [ ] 未验证模型有明确标签，不假装支持结构化输出/长上下文。

### 生成与阅读

- [x] Job/Stage 每个合法与非法转换有穷举矩阵；持久转换使用 CAS，过期写者和时间倒退不能覆盖，任务不能在仍有未成功阶段时假完成。
- [x] 同一 Stage 的两个执行器并发领取只有一个成功；租约到期后旧执行器不能靠迟到心跳或状态写入复活，请求意图后的过期工作不会盲目重试。
- [x] 网络发送授权只能在 RequestIntent、Attempt、未知 Usage 与 Stage 同事务提交后取得；授权前再次验证租约，半事务、敏感快照、过期或重复 permit 均不能获得发送权。
- [x] Provider 只能由审计后的受控执行器打开；增量仅进入加密草稿，2 秒/32 KiB 节流、4 MiB 上限、旧 writer 栅栏和独立租约心跳已有双 AVD 证据。
- [x] 结构化结果执行严格 UTF-8/JSON/版本/契约/资源上限校验；只允许一次有界格式修复，第二次、不可修复或无剩余名额时持久暂停，重启不会重置次数。
- [x] 正式章节、摘要/人物事件/事实/时间线/伏笔、最终用量、Stage、下一 Stage 和书进度在一个 SQLCipher 事务提交；任一步失败不留下半章或半套记忆。
- [ ] 第一章完成后可立即阅读，后续章继续生成。
- [ ] 正文生成时可读取已加密落盘的完整段落，界面明确标记为生成中；它不进入正式目录、索引、模板、导出或后续章上下文。
- [x] 未完整流不进入正式目录；异常、取消和乱序事件最多保留受保护草稿，既有 `ChapterVersion` 不变。
- [ ] 断网、杀进程、重启后已完成章节不丢失。
- [x] 暂停、继续、停止和取消当前章符合持久状态机：发送前不发请求；在途先取消并保存加密草稿；停止取消全部未完成 Stage；继续不直接联网；迟到回调不能复活任务。
- [x] 同一成功阶段的精确重放不重复版本、派生数据或章数；并发提交只有一个写者，用户改稿不会被迟到生成覆盖。
- [x] 未知结果不会因租约到期、超时或仅有 RequestIntent 自动重发；只有提供方证明未执行且本地证据一致才自动回队，用户确认与恢复查询本身均不调用生成接口。
- [ ] 达费用上限后无新请求。

### 模板

- [ ] 任一本书 3 次点击内可用原设定创建全新书。
- [ ] 新书重新生成标题、规划和正文。
- [ ] 旧正文、旧运行记忆、日志和密钥不进入模板新书。
- [ ] 来源书、父模板、修订和内容哈希完整。
- [ ] 编辑模板不会改变既有书快照。
- [ ] “只沿用风格”不带入具体人物/地点/剧情。

### 数据与安全

- [ ] 手动加密备份可以创建、自检和恢复。
- [ ] 错口令、损坏包、空间不足不会覆盖当前数据。
- [x] 正式数据库迁移没有破坏性清库回退。
- [x] 系统自动备份排除敏感数据。
- [ ] 远程 HTTP 被拒绝，跨 host 重定向无秘密。
- [ ] 首次向新远程 host 发送小说前明确说明数据类别和目的地；host 变化后重新确认。
- [ ] 明文 TXT/Markdown 导出与加密项目备份不混淆。
- [ ] 签名 APK 可覆盖安装旧候选版并保留数据。

## 2. 1.0 功能验收

### 长篇能力

- [ ] 20 章固定测试故事可完成完整管线。
- [ ] 人物身份、年龄、关系、位置、关键物品和时间线进入结构化记忆。
- [ ] 硬事实冲突在提交前被检测。
- [ ] 编辑第 N 章会使正确的派生链失效并重建。
- [ ] 后续正文不会被自动删除，用户能选择保留或重织。
- [ ] 中文关键词/别名检索达到基准集目标。

### API 兼容

- [ ] OpenAI Responses、Chat Compatible、Anthropic Messages、Gemini 原生通过完整夹具。
- [x] 四类首发适配器已通过模型列表 + 有界最小生成的本地编排夹具。
- [ ] 未知流事件不会崩溃。
- [ ] 策略拒绝不会自动重试或伪装成网络错误。
- [ ] usage 缺失/估算/精确三类能正确区分。
- [ ] Ollama 若纳入 1.0，NDJSON 和局域网 HTTP 限域通过测试。

### 阅读体验

- [ ] 暖纸、夜间、字号、行距、边距、滚动/分页可用。
- [ ] 阅读位置在重启、字体变化和覆盖升级后合理恢复。
- [ ] 目录可区分完成、生成中和计划章。
- [ ] 生成状态不遮挡正文、不强制跳章。
- [ ] 200% 字体和 TalkBack 完成主要流程。

### 费用

- [ ] 单次、单书、每日 token 硬上限均独立生效。
- [x] 当前开始前确认页在价格未知时不显示 0 元或虚构估算。
- [ ] 进入真实生成后，价格未知时 token 硬上限仍生效。
- [ ] 并发预算预留不能突破上限。
- [ ] 失败、取消、重试、续接用量进入台账。
- [ ] 价格表有版本和更新时间，历史不被重算。

## 3. 非功能发布闸门

- [ ] 所有 P0 自动化测试通过。
- [ ] S0/S1 缺陷为 0；S2 有书面接受理由和规避路径。
- [ ] 10,000 章目录压力测试通过。
- [ ] 连续流式和后台恢复无无界内存增长。
- [ ] 固定参考负载下，普通后续章首段 P95 ≤ 20 秒、正文结束 P95 ≤ 180 秒、正式提交 P95 ≤ 240 秒；第一章首段 P95 ≤ 90 秒、正式提交 P95 ≤ 300 秒。
- [ ] 5 分钟慢服务能停止新远程阶段并安全处置在途请求；正常章 10 分钟仍未结束时发布被阻断。
- [ ] 推荐模型档案来自至少连续 20 章的 P50/P95/最慢值，未验证或未达标组合不作为默认推荐。
- [x] 从每个支持的数据库版本迁移到最新通过。
- [ ] Release APK 无 debug 后门、测试 secret 或全信任证书。
- [ ] 第三方许可证清单完成。
- [ ] 签名密钥双备份、APK 哈希、恢复演练记录齐全。
- [ ] 所有项目产出和构建缓存配置在 `D:\gptuser`。

## 4. 用户体验验收口径

至少邀请用户本人以“完全不懂 API 术语”的方式走查：

- 首次连接不需要外部指导即可完成；
- 一句话到第一章过程中没有无法理解的技术选项；
- 模板重开不需要先整理模板库；
- 遇到错误知道下一步按哪个按钮；
- 阅读过程中不会因为后台生成被频繁打断；
- 能明确知道哪些数据会进入外部模型 API。

## 5. 不得豁免的项目

任何日期压力下，以下不可降级：密钥不泄露、费用硬上限、章节原子提交、模板排除旧正文/密钥、失败恢复不覆盖当前数据、正式迁移不清库、签名可升级、成年人明确性硬规则、正常章 10 分钟发布阻断。

应用锁、生物识别、`FLAG_SECURE` 和最近任务遮挡已由用户明确取消，不属于发布验收项；这不影响数据库、密钥、备份、通知和远程传输的其他安全要求。

## 9. TASK-051 初始规划链验收

- [x] Job 创建时冻结 `zhijuan.prompt-bundle.v1`，且只包含故事种子 → 故事圣经 → 全书总纲三个有序阶段；输入、依赖和幂等键均可确定性复算。
- [x] 三类结果都有 Provider 可见的完整 JSON Schema，并执行严格 UTF-8、重复键、字段、类型、长度、枚举、数量、标识符、哈希和未知字段校验。
- [x] 人物成人状态不能使用“不适用”；涉及亲密关系的人物必须是虚构且已确认成年，年龄与状态矛盾时失败关闭。
- [x] 故事圣经只能在已提交种子之后校验和落库，总纲只能在已提交圣经之后校验和落库；不能要求未来阶段结果才能提交当前阶段。

- [x] 精确重放不重复写入；阶段、书籍、租约、哈希或下一阶段任一不匹配时整笔事务回滚，不产生半套圣经、事实或总纲。
