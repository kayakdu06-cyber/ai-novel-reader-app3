## 6. 不得遗漏的产品硬规则

- 用户题材、背景、关系、机制、结构和文风输入完全开放；预设和状态适配器不是题材白名单。
- 短篇至少 80 章，中篇至少 300 章，长篇由用户填写 301～10,000 章。
- 默认少操作；一句设想可启动，高级资料可空，章节自动继续。
- 完成章节立即可读，后续章节后台生成。
- 模板复制保留来源、分类和版本，不复制旧正文、运行记忆或密钥。
- 真实 API 使用 DeepSeek V4 Flash，最高敏感度样本固定为“细写”档且角色明确为虚构成年人。
- 真实试写不评文笔，只验计划兑现、因果、重复、状态、敏感场景合同、完整性和速度。
- 正常章 10 分钟未完成阻断发布；3～5 章只报告逐章值、中位数和最慢值，至少 20 章才计算 P95。
- 本地数据库是权威事实源；模型结果校验后才可提交，正文、派生状态、用量和进度必须原子一致。
- 不做账号、会员、支付、社区、商城、后台、应用锁、生物识别、`FLAG_SECURE` 或最近任务遮挡。
- 不主动扩展功能，不重复测试等价风险，不把运行时 skill、插件或任意脚本放入 App。
