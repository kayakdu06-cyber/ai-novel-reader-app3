## 1. 使用规则

- 任务只有在代码、测试、文档和验收证据都完成后才能标“完成”。
- P0 不得用 TODO、假数据或“以后再补”穿过里程碑闸门。
- 每个任务提交需引用本表 ID；发现需求缺口先改文档和追踪矩阵。
- 工作量：S 约 0.5–1 天，M 约 2–4 天，L 约 5–8 天；仅用于排序，不是承诺。
- 关键路径：`E0 → E1 → E2/E3 → E4 → E5/E6/E7 → E8 → E9`。
