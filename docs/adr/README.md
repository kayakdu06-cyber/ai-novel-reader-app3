# 织卷架构决策记录（ADR）

ADR 用于记录编码后不容易改变、改变会造成明显返工的技术选择。

状态：

- `Accepted`：已决定，开发按此执行。
- `Proposed`：已有首选方案，需技术尖峰验证。
- `Superseded`：被新 ADR 替代，保留历史。

| [ADR-002](ADR-002-dependency-injection.md) | 依赖注入 | Accepted |
| [ADR-003](ADR-003-encrypted-storage.md) | 加密数据库与密钥 | Accepted |
| [ADR-004](ADR-004-chinese-search.md) | 加密数据下的中文检索 | Accepted |
| [ADR-005](ADR-005-application-id.md) | 应用 ID 与命名空间 | Accepted |
