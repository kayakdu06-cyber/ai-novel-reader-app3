# 织卷：产品简报

## 1. 一句话定义

织卷是一款本地优先、只供本人使用的 Android App：用户只写几句人物或故事设想，选择题材、阅读偏好和篇幅，App 自动把它发展成长、中或短篇小说，并允许用户在后续章节继续生成时立即阅读已完成内容。

## 2. 用户与场景

唯一目标用户是设备拥有者本人。典型场景：

- 临时想到一个人物关系，希望几分钟内开始读第一章；
- 想生成一部长篇，但不愿意手动维护复杂世界观和提示词；
- 上一本书方向不满意，希望沿用设定或风格一键重开；
- 使用 OpenAI、Anthropic、Gemini、OpenAI 兼容中转站或本地 Ollama；
- 在阅读过程中暂停、恢复、重试或修改局部设定，而不丢失已完成章节。

## 3. 核心价值

1. **少参与**：默认只需填写一句设想；角色、冲突、世界观、章节规划由 AI 补全。
2. **快进入阅读**：优先生成可读的第一章，长篇规划和后续章节按可靠队列继续。
3. **长篇不失忆**：用结构化故事圣经、章节摘要、人物状态和伏笔台账控制连续性。
4. **不满意可重开**：从任意旧书提取不可变模板快照，一键生成新书并保留来源。
5. **本地可掌控**：无业务后台；小说、设置、任务和备份由用户设备掌控。
6. **模型可替换**：通过统一适配层连接主流官方 API、中转站兼容 API和本地模型。

## 4. 产品原则

- 默认路径最多展示必要选项，高级选项折叠。
- 任何一步都提供推荐默认值，并解释实际影响，不要求用户理解 token、上下文窗或流式协议。
- 章节完成后立即提交为可阅读版本；未完整的流式草稿不得冒充完成章节。
- 所有长任务必须可暂停、可恢复、可审计、可限制费用。
- 用户修改正文或设定后，相关摘要和后续上下文必须自动失效并重建。
- 阅读模式中生成状态只能作为轻量状态出现，不抢占正文。
- 密钥永不进入小说模板、导出正文、普通日志和系统自动备份。

## 5. 目标

### G1：首次成功

新安装用户在 5 分钟内完成 API 连接，并在 10 分钟内开始阅读第一章；若 API 不可用，要得到清晰的单步修复建议。

### G2：可持续生成

应用被切后台、网络短断、进程被回收后，任务不会重复计费式无限重跑；重新打开后能解释当前状态并从安全检查点继续。

### G3：可读质量

中长篇能维持人物身份、关系、时间线、核心规则和主要伏笔；明显冲突要在发布章节前检测并尽可能自动修正。

### G4：重开效率

任一本书能在 3 次点击以内开始“同模板新书”；来源、版本和分类可追溯，但默认不要求用户整理。

### G5：隐私与可恢复

设备上的书可加锁、可手动加密备份、可验证恢复；更换 APK 版本时不会因数据库破坏性迁移而清空小说。

## 6. 非目标

- 不做登录、跨用户账户、云同步、会员、支付、广告、社区和运营后台。
- 不做多人协作、投稿、发布平台、版权交易或模型代理售卖。
- 不承诺任意模型都能生成任意内容；模型服务条款和拒绝由对应服务商决定。
- 不以一次超长请求生成整部长篇；长篇采用计划—分章—记忆—检查的流水线。
- MVP 不做桌面版、iOS 版和在线 Web 版。
- MVP 不做 EPUB 排版引擎级复杂能力；先保证 TXT/Markdown/项目备份。

## 7. 内容与责任边界

产品允许用户选择更含蓄或更细致的叙事呈现，但必须满足：

- 参与亲密情节的角色均为明确成年人；年龄模糊时不进入相关生成。
- 不允许真实人物性内容、未成年人性内容或将年龄规避写入模板。
- 非自愿、暴力和黑暗冲突作为独立的内部风险维度，不与“描写细致度”混为一项。
- App 不伪装服务商拒绝、不无限重试、不尝试绕过安全策略；允许用户切换到其合法拥有且自行负责的服务。
- “仅本人使用”降低了产品后台和账号需求，但不消除当地法律、设备安全、API 服务条款与账单风险。

## 8. 成功指标

本项目不追求商业增长指标，使用可靠性指标：

- 首次 API 连接成功率 ≥ 90%（正确凭证和可达网络前提）。
- 第一章从创建到可读的中位步骤数 ≤ 6 次点击、输入字段 ≤ 3 个。
- 崩溃后已完成章节丢失率为 0。
- 同一生成阶段因恢复造成的重复提交率 < 0.5%。
- 模板重开中，来源记录完整率 100%，密钥泄入模板率 0。
- 备份恢复演练通过率 100%。
- P0 自动化测试和手工发布闸门通过率 100%。

## 9. 交付阶段

- **内部骨架版**：书架、API 配置、单章流式生成、基本阅读器。
- **MVP**：分章队列、模板重开、费用上限、恢复、备份、两类 API 协议。
- **稳定版 1.0**：多协议适配、长篇记忆、编辑失效链、隐私加锁、完整迁移和发布验证。
- **1.x 增强**：更强中文检索、自动质量评分、模板导入导出、EPUB 等。
