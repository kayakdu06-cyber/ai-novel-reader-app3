# 织卷术语表

| 术语 | 定义 | 避免混用 |
|---|---|---|
| 连接 | 一组模型服务配置：协议、基础地址、密钥引用和模型 | 不叫“账号” |
| 提供方 | OpenAI、Anthropic、Gemini、Ollama 或兼容中转服务 | 不等同于具体模型 |
| 能力登记表 | 按连接、端点、协议、模型和证据来源记录输入、流式、usage 与限制，并按过期规则解析 | 不把名称猜测当事实，不把换地址前的能力带到新中转站 |
| 基础已验证 | 模型列表成功返回且所选模型存在；默认不发送生成请求 | 不代表所有生成能力都已验证 |
| 完整已验证 | 用户明确确认费用后，一次 16-token 固定通用探针得到有效终态 | 不代表内容尺度一定被该模型接受 |
| 尚未验证模型 | 列表端点确实不可用时手填并保存的模型 ID | 不等于连接失败，也不假装已兼容 |
| 故事种子 | 从用户简单输入标准化出的核心人物、欲望、阻力和卖点 | 不是完整大纲 |
| 故事圣经 | 稳定人物、世界规则、主题和禁改事实的版本化集合 | 不包含每章全文 |
| 总纲 | 全书主要阶段、转折和结局结构 | 不等同于分章计划 |
| 运行时记忆 | 已发生剧情形成的摘要、状态、时间线和伏笔 | 模板默认不复制 |
| 模板 | 可复用的生成配置逻辑对象 | 不是旧书副本 |
| 模板修订 | 不可变的模板内容版本 | 展示名称变化不一定创建修订 |
| 使用快照 | 某本书创建时实际采用的冻结模板内容 | 模板后改不影响它 |
| 模板新书 | 用模板从头生成一本新书 | 不复制旧正文 |
| 书分支 | 复制某本书到指定章节为止的内容和运行状态 | 不是模板新书 |
| 章节重试 | 为同一章生成候选版本 | 不新建书 |
| 检查点 | 持久化的阶段边界，可安全恢复 | 不等同于流式增量 |
| 正式章节 | 已通过最低检查并原子提交、可正常阅读的版本 | 未结束流不是正式章节 |
| 派生数据 | 可从正文/设定重建的摘要、索引、状态和上下文 | 编辑源内容后需失效 |
| 幂等键 | 防止同一逻辑阶段被误重复提交的稳定标识 | 不保证外部服务一定去重 |
| 用量台账 | 每个请求的 token、估价、状态和归属记录 | 不等同于服务商最终账单 |
| 硬上限 | 到达后系统必须停止发新请求的限制 | 不是仅提示 |
| 策略拒绝 | 服务方因内容或安全策略拒绝响应 | 不当作网络错误重试 |
| 请求送达状态 | 一次失败时对“未发送、服务端明确拒绝、响应已开始、结果不明”的证据分类 | 不等同于 HTTP 状态码，也不单独保证是否计费 |
| 重试等待预算 | 同一逻辑请求允许自动等待的累计上限，默认 15 分钟 | 不等同于生成费用预算 |
| 留白 | 更倾向转场、暗示和余韵的呈现档位 | 不等于无情节 |
| 均衡 | 情节推进与过程细节平衡的呈现档位 | 默认值 |
| 细写 | 更多过程、动作、心理和环境细节的呈现档位 | 不承诺服务商接受所有内容 |
| 呈现指令 | 外部档位映射出的总体细节、亲密细节、淡出策略和继承维度声明 | 不是已经解析完成的题材强度配置 |
| 严格身体与感官连续性 | 细写、避免淡出且成年人门禁通过时自动启用的场景执行要求 | 不等于机械罗列感官，也不允许绕过门禁 |
| 必需上下文 | 本章请求必须完整携带的应用规则、成年/身份事实、硬事实、目标计划和承接等材料 | 不能为省 token 截断或删除 |
| 可选上下文 | 主题、旧摘要、历史事件/时间线、未到期伏笔和远期计划等可按预算整项省略的材料 | 不代表事实被删除，只是本次不发送 |
| 上下文清单 | 不可变记录已选/省略项、优先级、内容 hash、预算和来源证据的 `chapter-context-manifest.v1` | 不等同于 Provider 原始响应或用户模板 |
| 上下文快照 | 某一章节计划实际准备发送的冻结 payload 与清单 | 来源变化后不能继续发送旧快照 |
| 正文流契约 | Provider 正文阶段使用的 `chapter-draft.v1` 单 `body` JSON 包络 | 不是正式章节对象，也不允许夹带标题、状态或解释 |
| 续接锚点 | 已保存正文末尾 96 个 Unicode 码点；续接开头必须精确复现后再由本地剥离一次 | 不是模糊相似度匹配，也不重复写入正文 |
| 自动续接 | `LENGTH` 后由系统以新 Attempt、独立用量和新加密草稿继续同一章节 | 最多 3 次，不绕过费用、attempt 或 4 MiB 上限 |
| 章节记忆 | `chapter-memory.v1` 产生的章节摘要、人物事件和事实 | 不含时间线/伏笔投影，也不等同于正文 |
| 来源版本绑定 | 章节记忆同时绑定最终版本 ID、正文 SHA-256、章节 ID 和序号 | 不是只靠章节序号猜来源 |
| 候选记忆 | 从冻结、已预分配最终版本 ID 的待提交正文提取的派生候选 | 修订后必须重提取，TASK-059 原子提交前不是正式记忆 |
| 记忆重建 | 从当前正式章节版本重新提取派生数据 | Provider-open 和提交前都要重验当前版本，不等于重写正文 |
| 故事追踪投影 | `chapter-story-tracking.v1` 产生的关键时间线事件与伏笔操作 | 不续写正文，也不替代 `chapter-memory.v1` |
| 伏笔当前投影 | `foreshadow_item` 中供后续章节快速读取的当前状态 | 不是完整历史；失效时不能继续使用 |
| 伏笔转换台账 | `foreshadow_transition` 中追加保存的 PLANT/DEVELOP/RESOLVE/ABANDON 来源记录 | 不允许覆盖旧转换或跳过中间依赖 |
| 中间状态依赖 | 当前伏笔结果曾经经过的早期章节转换 | 即使当前来源已前移，早期版本变化仍会使它 STALE |
| 本地一致性检查 | 不调用模型即可验证的来源、正文边界、人物/年龄、地点、物品、时间和必需事件规则 | 发现 blocker/major 时不产生模型检查费用 |
| 一致性检查报告 | `chapter-consistency-report.v1` 的结构化问题矩阵 | 不含改写正文或自由证据摘录，也不等同于正式章节 |
| 检查标准矩阵 | 本次策略要求模型按固定顺序逐项返回的 23 个标准 | 不能缺失、重复、乱序或用总分替代 |
| 关键过程证明 | 严格场景对每个冻结过程节点返回 COVERED/MISSING 的结果 | 不是正文摘录；缺失必须绑定固定问题 |
| 接受候选 | 检查结果只有 minor 或无问题，允许进入最终提交编排 | 不表示章节已经写入书库或可阅读 |
| 退修候选 | 本地或模型检查存在 blocker/major，要求进入有限修订 | TASK-059 前不会自动循环改稿 |
