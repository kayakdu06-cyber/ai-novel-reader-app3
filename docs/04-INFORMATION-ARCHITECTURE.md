# 织卷信息架构

## 1. 一级导航

底部只保留三个入口：

1. **书架**：小说项目、最近阅读、生成状态。
2. **模板**：系统预设、从书提取和用户自建模板。
3. **设置**：连接、生成默认值、阅读、隐私、备份、诊断、关于。

创建小说是书架页主按钮，不增加第四个底部页。

## 3. 书架信息层级

### 3.1 默认状态

- 顶部：产品名、搜索入口、设置入口。
- 第一块：最近阅读的一本书，可直接继续。
- 主列表：封面 + 书名 + 最近章节 + 阅读进度。
- 生成中的书额外显示：`正在织第 8 章`、`已暂停：达到今日上限`等一句状态。
- 右下主按钮：`织一本新书`。

### 3.2 状态优先级

错误需用户处理 > 达到费用上限 > 正在生成 > 已暂停 > 已完成 > 普通阅读进度。每张卡只显示一个最高优先状态，避免堆叠。

## 4. 新建页渐进披露

首屏最多四个决策：一句设想、题材、篇幅、呈现档位。以下内容折叠在“再补充一点”：

篇幅选择仍保持三张单选卡：短篇最低 80 章、中篇最低 300 章；只有选择长篇时才渐进显示目标章数输入。长篇字段默认留空、必须由用户填写 301–10,000，未填写时给出中性说明，越界时在字段旁直接报错。

- 人物与关系：姓名可空；可写年龄、身份、性格和关系。涉及亲密关系时提示写明相关人物均为 18 岁以上；未写时由后续标准化补成明确成人设定，无法确认则不进入相关生成。
- 世界与背景：时代、地点、规则、社会结构合并为一组自然语言输入。
- 叙事与文风：视角、人称、节奏、文风、章节长度合并为一组自然语言输入。
- 希望保留 / 不想出现：分成两组自由输入；内部内容强度由 TASK-035 的三档版本化映射自动生成，不在默认页面增加专业参数。
- 模型：默认跟随当前连接，专家用户才选择阶段模型。

展开高级项后再次创建时保留展开状态，但不强迫填写；折叠、旋转、Activity 重建以及临时进入连接管理再返回时不清空内容。

### 4.1 开始前确认

- 页面只消费已提交的不可变快照，不接收整份表单作为第二事实来源；导航只保存书 ID，进程重建后重新读取。
- 默认只显示书名、篇幅、目标/最低章数、当前模型和费用可信状态，避免暴露哈希、schema 或连接凭据。
- 价格未知使用完整句子说明，不能显示 0 元、虚构 token 范围或根据模型名猜价。
- 读取失败显示“没有开始生成、没有调用模型”和唯一返回动作；确认成功后按钮锁定，避免重复操作。
- 当前占位页不越权启动生成；真实预算、host 数据发送确认和执行器接入后，才允许进入生成队列。

## 5. 小说详情页

分为：

- **主要动作**：继续阅读 / 开始生成 / 继续生成。
- **状态卡**：当前阶段、完成章节、下一动作、费用/用量。
- **内容概览**：简介、人物、世界、规划；默认只读摘要，编辑进入二级页。
- **更多动作**：重新织一本、从此处分支、导出、归档、删除。

危险动作规则：

- 删除书使用二次确认并展示章节数和最近备份时间。
- “停止生成”不是删除；不放在红色危险区。
- “重新织一本”创建新书，绝不覆盖原书，确认页要明确这一点。

## 6. 模板页

默认呈现：最近使用、收藏、从书提取、系统预设。模板卡展示：

- 模板名；
- 题材与风格标签；
- 来源简写，如“来自《旧书名》· 第 2 版”；
- 最近使用时间；
- 主动作“用它织书”。

详细来源链放在详情页，格式示例：

```text
系统预设「都市悬疑」v3
  → 用户调整「慢热双主角」v1
    → 来自《夜班列车》创建快照
      → 当前模板「夜线重开」v2
```

分类允许用户改标签、名称、收藏和归档；不可篡改系统记录的来源、父版本、创建时间和内容哈希。

## 7. 阅读器信息层级

- 默认：仅正文、章节标题和极弱进度提示。
- 点击正文中部：顶部栏、目录、上一章/下一章、阅读设置、生成状态浮现。
- 目录侧滑：已完成章正常显示，生成中显示微弱动态状态，计划章不制造“已经可读”的错觉。
- 正文末尾：下一章未完成时显示轻量占位和“继续阅读已有内容/查看进度”，不展示技术日志。
- 编辑入口位于章节菜单，不常驻正文。

## 8. 设置页层级

设置按用户任务命名，不按技术模块命名：

| 用户看到 | 实际内容 |
|---|---|
| 模型连接 | 提供方、地址、密钥、模型、测试 |
| 生成偏好 | 默认题材、篇幅、呈现、自动继续 |
| 用量与上限 | 每日/单书/单次限制、台账 |
| 阅读设置 | 字号、行距、主题、翻页 |
| 数据与隐私 | 本地加密、通知内容、外部发送说明 |
| 备份与恢复 | 加密包、恢复演练提醒 |
| 诊断 | 错误记录、能力信息、脱敏导出 |

## 9. 空状态

- 无书：一句话说明 + `织第一本书`。
- 无模板：仍展示系统预设；若系统预设损坏，提供“恢复预设”。
- 无连接：创建按钮进入连接引导，不显示技术错误页。
- 无网络：已下载/本地书完全可读；生成卡显示等待网络。
- 无可用模型：保留连接，提示手填模型或重新获取。
